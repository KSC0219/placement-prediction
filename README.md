# Placement Prediction Using Machine Learning

A Python machine learning application that predicts whether a student will be placed in campus recruitment, based on academic scores, skills and experience.

## Highlights

- **Data pipeline:** the CSV is loaded into a SQLite database, and the training data is pulled with SQL queries that filter out invalid records.
- **Preprocessing:** removes duplicates, normalises text, clips out-of-range values, imputes missing values, scales numeric features and one-hot encodes categorical ones. Everything is wrapped in a scikit-learn `Pipeline`, so the same steps run at training and prediction time.
- **Model selection:** compares Logistic Regression, Decision Tree, Random Forest, Gradient Boosting and KNN with stratified 5-fold cross-validation, then keeps the best model by F1 score.
- **Evaluation:** reports accuracy, precision, recall, F1, ROC-AUC and the confusion matrix on a held-out test set.
- **Prediction CLI:** predicts placement for a new student from the command line.
- **Tests:** pytest covers the data cleaning, the SQL filtering and the model behaviour.

## Tech stack

Python · Pandas · NumPy · Scikit-learn · SQL (SQLite) · pytest

## Dataset

`data/placement_data.csv` has 2,000 student records with these columns:

| Column | Description |
|---|---|
| `gender`, `branch` | Male/Female; CSE, IT, ECE, EEE, MECH or CIVIL |
| `ssc_percentage`, `hsc_percentage` | 10th and 12th class percentages |
| `cgpa` | Degree CGPA (out of 10) |
| `internships`, `projects`, `certifications` | Counts |
| `aptitude_score` | Aptitude test score (out of 100) |
| `soft_skills_score` | Soft skills rating (out of 10) |
| `backlogs` | Number of backlogs |
| `extracurricular` | Yes / No |
| `placed` | **Target**: 1 = placed, 0 = not placed |

> The dataset is **synthetic**: it is generated by `src/placement/generate_data.py` with realistic distributions. To use a real dataset, put a CSV with the same columns at `data/placement_data.csv` and retrain.

## Getting started

```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Train

```bash
python -m src.placement.train
```

### Predict for a student

```bash
python -m src.placement.predict --cgpa 8.4 --aptitude 80 --internships 1 --branch CSE
# LIKELY TO BE PLACED (probability 96.8%)

python -m src.placement.predict --cgpa 6.1 --aptitude 45 --backlogs 2 --branch MECH
# NOT LIKELY TO BE PLACED (probability 4.4%)
```

Run `python -m src.placement.predict --help` to see every option.

### Run the tests

```bash
python -m pytest
```

## Results

Cross-validation F1 on the training set:

| Model | CV F1 |
|---|---|
| **Logistic Regression** | **0.788** |
| Random Forest | 0.786 |
| KNN | 0.774 |
| Gradient Boosting | 0.773 |
| Decision Tree | 0.711 |

The best model (Logistic Regression) on the held-out test set: **76% accuracy, 0.80 F1 for the "Placed" class, and 0.83 ROC-AUC.**

The SQL analysis shows that placement rates are highest for IT (66%) and CSE (63%), and lowest for CIVIL (49%).
